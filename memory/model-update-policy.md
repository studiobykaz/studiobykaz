# Model Update & Notification Standard

## Core Policy
1. **No Unilateral Changes:** Never automatically switch, add, or alter primary or fallback models when new models are released by Google, OpenAI, or OpenClaw upstream.
2. **Proactive Notification:** Whenever new models appear in upstream OpenClaw releases or provider registries, explicitly notify Kevin with details on capabilities and pricing.
3. **Explicit Consent Required:** Only modify `openclaw.json` model configurations upon explicit user instruction.
